Why open-source AI?

SlothTidy runs Qwen3 locally through Ollama. No API keys, no cloud, no subscriptions. Here's why that matters for a file organizer:

Privacy by default

Bank statements, tax forms, resumes, medical docs — your Downloads folder is intimate. With a local model, nothing leaves your RAM. No data ever hits an external server.

Works offline

Organize files on a plane, a train, or during an outage. No internet required, no API timeouts, no dependency on someone else's infrastructure.

Zero ongoing cost

Closed APIs charge per token and throttle batch requests. SlothTidy processes unlimited files at zero cost, forever.

Swap models freely

Switch between Qwen3 1.7B and 0.6B, or drop in Llama, Mistral, or Phi. One config change, zero code changes. You're never locked in.
